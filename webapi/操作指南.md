# HEMIT WebAPI 操作指南

> 本文档说明如何在 Windows 上运行 HEMIT 模型推理 API。

---

## 一、项目文件说明

```
webapi/
├── app.py              # FastAPI 主应用（API 端点定义）
├── config.py           # 配置模块（端口、设备、权重路径等）
├── real_model.py       # 模型推理模块（加载 ResnetGeneratorSwinT）
├── requirements.txt    # Python 依赖列表
├── .env                # 环境变量配置
├── outputs/            # 生成结果存储目录（自动创建）
└── 操作指南.md          # 本文档
```

---

## 二、环境准备

### 2.1 确认 Python 已安装

打开 **PowerShell** 或 **命令提示符**，运行：

```bash
D:/py/python.exe --version
```

应输出 `Python 3.10` 或更高版本。

### 2.2 确认 Node.js 已安装

```bash
node --version
```

应输出 `v18` 或更高版本。

### 2.3 确认预训练权重文件

确保 `D:\毕业设计\hemit_v1.pth`（约 441MB）存在。这是 ResnetGeneratorSwinT 双分支生成器的预训练权重。

---

## 三、安装依赖

在终端中运行：

```bash
cd d:\毕业设计\webapi
D:/py/python.exe -m pip install -r requirements.txt
```

这会安装以下库：
- `fastapi` — Web 框架
- `uvicorn` — ASGI 服务器
- `pillow` — 图像处理
- `numpy` — 数值计算
- `pydantic-settings` — 配置管理
- `torch` + `torchvision` — PyTorch 深度学习推理
- `timm` 0.4.12 — Swin Transformer 依赖
- `einops` — 张量重排操作

如果 PyTorch 安装较慢，可使用清华镜像：
```bash
D:/py/python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 五、测试 API

### 5.1 用 Swagger 测试页面测试

1. 打开浏览器，访问 **http://127.0.0.1:8000/docs**
2. 你会看到 FastAPI 自动生成的 **Swagger UI** 测试页面
3. 找到绿色的 **`POST /api/v1/convert`** 接口
4. 点击右侧的 **"Try it out"** 按钮
5. 在 `file` 字段点击 **"选择文件"**，选一张 H&E 染色图像
6. `resolution` 保持默认 `high`（或选择 `low` 加快速度）
7. 点击蓝色的 **"Execute"** 按钮
8. 等待推理完成（CPU 模式下约 30-120 秒）

### 5.2 查看返回结果

执行成功后，你会在页面下方看到类似以下 JSON 响应：

```json
{
  "status": "success",
  "message": "图像转换成功",
  "data": {
    "result_id": "a1b2c3d4-...",
    "dapi_url": "/outputs/a1b2c3d4-.../channel_dapi.png",
    "panck_url": "/outputs/a1b2c3d4-.../channel_panck.png",
    "cd3_url": "/outputs/a1b2c3d4-.../channel_cd3.png",
    "composite_url": "/outputs/a1b2c3d4-.../composite.png"
  },
  "metadata": {
    "resolution": "high",
    "original_filename": "your_image.jpg"
  }
}
```

### 5.3 查看生成的图片

在浏览器地址栏直接访问返回的 URL，例如：

```
http://127.0.0.1:8000/outputs/a1b2c3d4-.../composite.png
```

你会看到一张带有蓝、绿、红色调的伪彩色荧光图，分别对应 DAPI（细胞核）、CD3（T 细胞）、panCK（肿瘤区域）。

## 六、API 接口说明

| 接口 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 根路径，返回服务状态 |
| `/api/health` | GET | 健康检查，前端用此判断后端是否在线 |
| `/api/v1/convert` | POST | **核心接口**：上传 H&E 图像，返回三通道结果 |
| `/docs` | GET | 自动生成的 Swagger API 文档 |

### `/api/v1/convert` 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `file` | 文件 | 是 | H&E 染色图像（支持 jpg/png/tif） |
| `resolution` | 字符串 | 否 | `"high"`（1024x1024）或 `"low"`（512x512），默认 `"high"` |

## 七、配置说明

编辑 `webapi/.env` 可修改以下配置：

```ini
# 服务器配置
HOST=0.0.0.0
PORT=8000

# 模型配置
MODEL_WEIGHTS_PATH=D:/毕业设计/hemit_v1.pth
DEVICE=cpu              # 如有 NVIDIA GPU 可改为 cuda

# 文件存储
OUTPUT_DIR=./outputs
MAX_FILE_SIZE=50        # 最大上传文件大小（MB）
```

修改后重启后端服务即可生效。

## 八、在 PyCharm 中操作

如果你使用 PyCharm：

1. **打开项目**：`File -> Open -> 选择 d:\毕业设计\webapi 文件夹`
2. **配置 Python 解释器**：`File -> Settings -> Project -> Python Interpreter -> 选择 D:/py/python.exe`
3. **打开终端**：点击 PyCharm 底部的 `Terminal` 标签

5. **运行服务**：在终端中运行 `D:/py/python.exe app.py`
6. 或者直接右键 `app.py` -> `Run 'app'`

## 九、常见问题

### Q: 启动报错 `ModuleNotFoundError: No module named 'fastapi'`
**A:** 说明依赖没有安装到当前 Python 环境。运行：
```bash
D:/py/python.exe -m pip install -r requirements.txt
```

### Q: 启动报错 `ModuleNotFoundError: No module named 'torch'`
**A:** 需要安装 PyTorch：
```bash
D:/py/python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
D:/py/python.exe -m pip install timm==0.4.12 einops
```

### Q: 启动报错 `FileNotFoundError: 权重文件不存在`
**A:** 确认 `hemit_v1.pth` 存在于 `D:\毕业设计\hemit_v1.pth`，并检查 `.env` 中 `MODEL_WEIGHTS_PATH` 路径是否正确。

### Q: 浏览器打不开 `http://127.0.0.1:8000/docs`
**A:** 检查终端中是否有报错信息。如果端口被占用，可以修改 `.env` 文件中的 `PORT=8001`。

### Q: 上传图片后推理很慢
**A:** CPU 模式下处理 1024x1024 图像约需 30-120 秒，属于正常现象。可选择 `low` 分辨率（512x512）加快速度。如有 NVIDIA GPU，可修改 `.env` 中 `DEVICE=cuda`。
